# AI Usage Log

This project was developed with AI assistance through Copilot SDK in VS Code.

## Where AI assisted

- Reviewed the submission guidelines and repository readiness.
- Inspected the generator, FastAPI backend, frontend, SQLite output, and documentation.
- Ran smoke and full-scale generation, validation, reproducibility, backend, and frontend checks.
- Identified documentation gaps, the partial backend fallback behavior, and the missing root-level Git ignore rules.
- Reorganized planning documentation under `prompt-library/`.
- Expanded the README, documented engineering decisions, and prepared Mermaid diagrams from the implemented workflow and SQLite tables.

## Human review and validation

The project owner reviewed the requested documentation and behavior changes. Runtime claims were checked against generated output, command results, API responses, and the implemented source rather than being inferred only from the planning documents.

Known limitations and the GT-002 schema gap are disclosed in `DECISIONS.md` and the README.
